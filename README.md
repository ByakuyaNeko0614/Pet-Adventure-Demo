# Pet Adventure (Demo) · 寵物尋寶

霧谷探險隊是一款寵物養成與迷宮遊戲。夥伴會自主找寶箱、累積攜帶，並決定何時送往出口。新迷宮有兩個出口，依難度距起點至少 12／14／16／17 步。地圖下緣用一句心聲和三條進度條顯示夥伴狀態；玩家可花引導點指路或指定目標。

## 本機 Demo

需要 Node.js 22 以上。進入此專案資料夾後執行下列指令，瀏覽器開啟 [本機遊戲](http://127.0.0.1:5173/)。

```powershell
npm start
```

本機遊戲使用原生 HTML、CSS、JavaScript 與 Node 內建 HTTP 伺服器。Apps Script 建置需要先執行 `npm ci`。預設綁定 `127.0.0.1`。需要更換連接埠時，可在啟動前設定 `$env:PORT = '5174'`。Demo 的永久存檔放在目前瀏覽器、設定檔與網址來源的 `localStorage`，請用同一網址讀取原來的資料。`localhost` 與 `127.0.0.1` 有各自的存檔。

### 試玩流程

1. 從「寵物窩」前往孵化室。第一顆蛋免費，點了就破殼；看見寵物後再取名。後續每顆蛋隨已孵化數增加費用與等待時間，離開頁面仍會計時。
2. 開啟「迷宮探索」，可先看選中寵物的體力、膽量、耐心目前值和上限，再選擇難度及委託。委託會記住同一瀏覽器上次選的項目。按「開始探索」後，寵物每 1.2 秒自主移動一格，也可選擇 2.5 秒或 0.65 秒。上方固定面板可暫停、繼續或單步。
3. 地圖上的 1、2、3 標示夥伴預計經過的格子；下緣顯示一句心聲，以及體力、膽量、耐心進度條。
4. 方向鍵或地圖上的虛線格可引導一步，每步消耗 1 點引導點。操作後會暫停，可使用補給，再按空白鍵繼續。
5. 夥伴通常會自行決定繼續搜寶或撤離。指定目標消耗 3 點，按 0 可免費恢復自主。遺跡與出口抉擇可按畫面提示的數字鍵作答。
6. 把寶箱送到任一出口後，可選擇領取獎勵結束，或維持剩餘資源繼續冒險。之後失敗，已送達的金幣、經驗、道具各保留 50% 並向下取整；身上尚未送達的寶箱全部失去。出口面板會顯示兩種結算金額。難度獎勵與委託獎勵每場只給一次。
7. 結算後可到商店購買補給或養成道具，或查看、重播冒險紀錄。在背包點「使用」、選擇在家的寵物，再確認使用。

以夥伴目前的狀態出發。現行的地形、搬貨與恢復泉數值如下。搬著寶箱踏入出口、或踏入未使用泉水時，允許用完最後一點體力。每箱價值 6–12 金幣，40% 機率附帶一道具；可以同時攜帶多箱，送達前不計入獎勵。泉水與寶箱每格只領一次。估計回不去時，心聲會先提醒；往目標的下一格真的走不動才會暫停並提示缺哪項資源。補給後可按空白鍵繼續。放棄會捨棄獎勵，已消耗的狀態與道具會保留。

| 難度 | 平地／沼澤體力 | 森林額外膽量 | 每箱每步額外體力 | 泉水 |
| --- | --- | --- | --- | --- |
| 簡單 | 1／3 | 2 | 0 | 4 座，各最多 20 |
| 普通 | 1／6 | 5 | 1 | 2 座，各最多 12 |
| 困難 | 2／8 | 7 | 2 | 1 座，最多 8 |
| 極限 | 2／10 | 9 | 3 | 1 座，最多 5 |

極限每場只可各帶一份活力露和勇氣茶。安全撤離會取得較高的難度獎勵與一個天賦道具；不必將天賦全練滿才可挑戰。

v13 新冒險的寵物會自動使用種族能力。貓的夜視減少森林膽量消耗，小龍的低空滑翔減少沼澤地形體力消耗，兩者皆減免原費用的三分之一並向上取整。小龍搬貨的額外費用照常計算。狐狸使用未領取的泉水時可額外恢復最多 4 點膽量，兔子空手踏入平地時少扣 0.25 體力。出發前可以查看能力，地圖格會顯示這隻寵物的移動費用。

每次移動消耗 0.25 耐心，與難度、地形無關。耐心越少，寵物自主決定是否再拿一箱時，願意考慮的距離越短；它也微調寵物對步數的重視程度。耐心歸零不會阻止移動或撤離。等級上限為 12，升級所需經驗是 `24 + 10 × 當前等級`。升級增加 4 體力、2 膽量、1 耐心，對應能力的基本上限分別為 115、55、48。每項個體值高於 40 的部分，可再增加對應上限，最高為 125、65、58。

出生時體力、膽量、耐心個體值合計 80–100，各項最多 40；可以用活力果、勇氣果或橡果徽章培養到 50。練到 41～43 需 Lv. 5，44～46 需 Lv. 8，47～50 需 Lv. 11。確認前會看到成功率與保底；同一寵物的同一項連續失敗三次，第四次必定成功。結果會留在背包內，即使道具用完也能看到。

家園可以預覽並解鎖玻璃花房（110 金幣）與月光閣樓（200 金幣）。在夥伴所在的房間點牠，再用「搬房間」指定新住處，搬家免費；每個房間只顯示住在那裡的夥伴，並有自己的背景與配樂。點房間裡的毛線球或「一起玩球」，夥伴有空時會追球、把球拍走。

兩種 Repository 使用同一套資料命令。Demo 透過 `localStorage` 讀寫，在支援 Web Locks 的瀏覽器會序列化跨分頁交易。Sheets 頁面透過 `google.script.run` 呼叫 `gameApi`，伺服器使用 `LockService` 和 Sheets API 的批次更新。商店價格與金幣由資料層重算。結算時以原始探索票券和操作紀錄重播終局，再一次提交獎勵、背包、經驗、紀錄與已結算票券狀態。相同冒險不會再發一次獎勵。

### AI 怎麼走

- **Behaviour Tree（版本 4）** 先看玩家目標指令；自主模式再看已承諾的撤離目標、體力與膽量、攜帶數量、下一箱距離和回程餘裕。膽小型傾向 1 箱撤離、穩重／急躁型 2 箱、冒險型 3 箱；這是自主偏好，不是背包上限。玩家可強制繼續搜寶。低體力且附近有泉水時可以先補給，無可負擔的下一箱則帶貨返程。
- **BFS** 驗證出口連通，最短搬運步數為「起點 → 任一寶箱 → 任一出口」，只計步數。
- **資源約束尋路** 同時保留成本、體力、膽量不同的可行路徑，確認整段路可負擔，避免只檢查下一格而反覆折返。評估再拿一箱時，也估計從該寶箱回出口的消耗與性格所需的保留體力；不預支尚未使用的泉水補給。
- **穩定目標** 版本 4 不隨機亂走，性格和耐心仍影響距離、體力、膽量的成本偏好。已決定撤離時保持目標，不因每步情緒變動而往返切換。玩家指令只改目標，仍須遵守地形、路障和資源限制。
- **情緒** 保留隨移動更新的情緒顯示；版本 4 路線成本使用穩定的性格權重，情緒不再逐步擾動路線。
- **三步預覽** 先準備目前版本的決策，再複製移動狀態，沿用同一套事件、資源和情緒規則推算後續。實際移動沿用已顯示的第一步。干涉或使用補給後會遞增版本，從新的狀態更新三步。

地形與獎勵數值集中在 `core/rules.js`，自主搬運偏好與回程保留量在 `core/decision.js`。舊版 1–3 的決策、隨機改道和開箱事件依票券版本保留，確保舊紀錄仍能重播。

### Seed 與重播

探索頁的「種子與地圖管理」可設定地圖 Seed 與決策 Seed。留空時隨機產生；同樣的地圖 Seed 和難度會生成同一張圖。可固定地圖 Seed，換一隻性格不同的寵物，或只改決策 Seed。探索中顯示的 Seed 以「目前這場」為準，設定欄供下次出發使用。出發時也會登錄地圖，這裡可以儲存、修改或刪除地圖。

冒險紀錄的「重播」會以當時的寵物快照、地圖與決策 Seed、事件 Seed、規則版本和玩家操作還原路線。匯出 JSON 可查看每步選擇、原定方向、權重和玩家操作。UI 重繪與暫停不會改變已準備的決策。直接以相同 Seed 重開時，寵物起始能力、背包與操作也需要相同，結果才會一致。修改規則時應更新 `Rules.version`；如需讓舊紀錄跨版本重播，應保留舊版引擎。

## Google Sheets Mode

玩家用獨立的帳號名稱和密碼登入，同一本私人試算表依玩家 ID 保存各人的進度。公開的遊戲網址由 Apps Script 提供。GitHub 保存原始碼與建置流程。

1. 建立空白 Google 試算表，從網址取得 `/d/` 與下一個 `/` 之間的 ID。
2. 執行 `npm ci` 和 `npm run build:gas`。在新的 Apps Script 專案匯入 `dist/gas/` 裡的所有 `.gs` 與 `.html`，並替換 `appsscript.json`。可使用 clasp 推送建置目錄，或透過 Apps Script 編輯器建立同名檔案。若使用標準 Google Cloud 專案，也要啟用 Sheets API。
3. 在 Apps Script 的「專案設定 → 指令碼屬性」設定 `SPREADSHEET_ID` 和 `OWNER_EMAIL`。由部署者在編輯器執行 `initializeGame` 並授權，建立 `Accounts`、`Players`、`Pets`、`Maps`、`Inventory` 與 `AdventureLogs`。
4. 在「部署 → 新增部署」選擇網頁應用程式，執行身分選「我」，存取權選可讓遊戲受眾開啟網址的選項。如果要讓沒有 Google 帳號的人登入，需選「任何人」。部署介面會依 Google 帳號的管理員政策提供選項。試算表維持私人。
5. 開啟部署網址並建立兩個測試帳號。以其中一個帳號孵蛋，確認第二個仍從第一顆蛋開始。登出後再次登入第一個帳號，確認存檔能讀回。之後修改程式需重新建置、匯入並更新部署版本。

帳號名稱允許 3–24 個文字、數字、底線或連字號，英文不分大小寫。密碼長度是 15–128 個字元，以獨立鹽值及 PBKDF2-HMAC-SHA256 驗證。每次存檔都依有效登入取得玩家 ID。登入狀態在同一瀏覽器分頁可跨遊戲頁使用，最長七天。尚未提供自助找回密碼。

若用原本的單人版試算表，先備份一次。初始化會補上 `Accounts` 和地圖的玩家欄位。從遊戲註冊接收帳號後，先不要用該帳號孵蛋或更動進度。在指令碼屬性填 `LEGACY_TARGET_USERNAME`，再由擁有者從編輯器執行 `migrateLegacySave`。這會將舊雲端存檔移到該帳號。本機 Demo 存檔仍由瀏覽器保存。

官方參考：[Apps Script 網頁應用程式](https://developers.google.com/apps-script/guides/web) · [clasp 匯入部署](https://developers.google.com/apps-script/guides/clasp) · [Advanced Sheets Service](https://developers.google.com/apps-script/advanced/sheets)。

Pets 的 CRUD 對應孵化、查看、改名／養成、放生；至少要留下一隻夥伴。Maps 對應儲存、選取、重建和刪除。Inventory 由購買或領獎建立或更新數量，使用到零時移除。AdventureLogs 可讀取、重播、匯出及刪除。刪除地圖或寵物後，紀錄仍帶有當時的快照。

## 測試與限制

```powershell
npm test
npm run build:gas
```

自動化涵蓋地圖連通、尋路、性格偏好、隨機範圍與重現性、三步預覽、干涉、事件、計時器、交易與持久化。Sheets 測試替身驗證欄位編解碼、命令、權限檢查和批次請求格式。正式 Google 帳號授權、Web App 載入與實際試算表寫入需在部署後驗收。

- Demo 存檔屬於瀏覽器本機資料。清除網站資料會重置進度。進行中的操作用同一分頁的 `sessionStorage` 恢復，另開分頁或嵌入環境禁用此儲存時，會從已存票券的起點繼續。
- 資料層保留最新 30 張地圖和 24 筆冒險紀錄。可事先匯出要長期留存的紀錄。
- 地圖生成保證幾何連通。實際體力、膽量、支線與干涉會影響能否通關。
- Sheets 驗證重播操作與獎勵，但無法驗證玩家是否真的逐格等待、是否透過開發者工具先查看決策，或是否事先挑選 Seed。試算表編輯者也能直接改資料。這套模式適合課堂展示或少量玩家的 Demo。


## 探索委託與引導

出發前選擇委託：限步快遞要求最短搬運路程加 8 步內送達；寶箱獵人要求送達至少 2 箱；平安回家要求送達時保留 40% 體力、50% 膽量。v9 的金幣獎勵分別為 6、11、7，另有 8 EXP。委託在出口達成時記入本場已送達獎勵，每場一次；繼續失敗時也適用 50% 規則。

地圖上的紅色路障代表干涉後暫時封住的原位，滑鼠停留可看剩餘步數。若干涉進入死路，寵物會解釋必須回頭的理由。心聲會說明當前目標、剩餘最少距離、下一格消耗、資源餘量，以及隨機改道或回頭的原因。

舊版探索與紀錄按各自版本執行。重新整理後開始新一場，才會使用版本 4 的多出口、自主累積搬運、目標指令與撤離抉擇。
## 舊版 3 的寶箱事件（僅歷史探索）

一般走路間隔為 1.2 秒，快速模式為 0.65 秒。遇到尚未開啟的寶箱時會自動暫停，三步預覽也只顯示到寶箱。穩拿獎勵可取得 8 金幣；冒險破解有 60% 機率取得 18 金幣與 1 個道具，失敗損失 6 體力並進入緊張情緒。體力至少要有 7 點才能選擇冒險。開箱不消耗干涉次數，開完後顯示結果，按繼續才再出發。

舊開箱選擇仍可重播；版本 4 已改為自動搬起寶箱，不再出現開箱選擇。出口選擇與玩家目標指令也會存入紀錄，可刷新還原與伺服端重播。

## 版本 5：隨機路線與地圖優先介面

每次開始探索預設產生新的地圖與決策種子。想重玩指定地圖時，展開「種子與地圖管理」、勾選「固定地圖」，再填入種子或選取儲存地圖。載入舊冒險不會讓下一場自動沿用舊種子。

有可行替代路線且冷卻結束時，膽小、穩重、急躁、冒險型的改道嘗試機率分別為 25%、35%、45%、60%。改道只走尚未訪問、靠近目前目標的格子；整段路必須有足夠資源，成本最多增加 30%、體力最多多花 2 點、膽量不可增加。改道後冷卻兩步。因此這不是每一步都會改道的機率。三步預覽仍展示真正準備執行的路線，並可重播。

寬螢幕採左側大地圖、右側想法及控制面板。窄螢幕的想法面板不再黏住視窗遮住地圖。版本 1–4 的紀錄仍使用原規則；新開一場才套用版本 5。

## 音樂、音效與操作回饋

寵物窩與探索的配樂、音效預設開啟。若瀏覽器阻擋自動播放，點擊畫面或按鍵後會重試。「音量設定」可獨立切換背景音樂、動作音效與總靜音，設定會保存在本機。迷宮配樂為《Steps on Mossy Stones》，小屋配樂為《午後小屋》，來源見 [AUDIO.md](web/assets/AUDIO.md)。落腳會依平地、森林、沼澤、泉水播放不同音色。

地圖下方有事件回饋列，靜音時仍可看到撿箱、送達、補給、指令確認與失敗提示。玩家選定的目標以深綠色標示。空白鍵切換暫停／繼續，方向鍵花 1 點引導一步。也能用 Tab 聚焦可引導的地圖格，再按 Enter 或空白鍵操作。切到其他分頁會暫停探索，配樂會繼續；回來後可自行繼續探索。

## 寵物窩與持續狀態（規則 v6）

- 主頁變成可互動的小屋，夥伴會依需求行為樹去食盆吃飯、去窩裡睡覺、安靜休息或散步；可以點夥伴摸摸、邀請休息、準備飯飯及玩球。連續摸摸會躲開，熟睡時不強迫叫醒。
- 小屋使用可分別動作的向量身體、頭、眼睛、尾巴與四肢，並支援減少動態效果。肚子與精神是小屋生活需求，儲存在目前瀏覽器；不扣金幣，不在離線時懲罰玩家。
- 體力、膽量、耐心有目前值及永久上限。冒險每步保存進度與消耗；耐心每步消耗 0.25，影響搜尋範圍。重新整理或再次出發不會補滿。尚有冒險時須先結束或放棄，放棄保留消耗及已用道具。
- 回家（含離線）每分鐘恢復體力 2、膽量 1、耐心 1，探索中的寵物不恢復。睡覺動畫反映疲倦；持續資源按同一個真實時間恢復率計算，不以動畫幀數發獎勵。
- 活力露／勇氣茶也可在家快速恢復；安心餅乾恢復耐心。活力果／勇氣果增加對應上限，橡果徽章增加耐心上限。上限提升不會直接補滿目前值。
- 舊寵物首次採用目前值時從滿值開始，舊版 1–5 冒險維持可重播。Sheets 既有欄位不增刪，Pets.mood 欄以 JSON 保留 mood 與 condition，讀取時相容舊字串。需重新匯入 build:gas 產物才會更新遠端版本。

## 橫向迷宮、引導點與孵化室（規則 v7）

新版地圖為 18 欄 × 8 列，舊票券與重播按原尺寸執行。地圖下緣同列顯示夥伴心聲與三條資源進度條。空白鍵暫停／繼續，N 單步，方向鍵指路，0 恢復自主，1、2、3 指定目標；遇到選擇時，按提示數字鍵作答。每場 5 點引導點，指路 1 點，指定目標 3 點，恢復自主免費。暫停時可按 Q、E 使用對應補給。

選「帶螢火燈回家」委託會標出遺跡。抵達可選 3 體力解下螢火燈，或帶走 28 金幣的錢袋。遇到可架便橋的地形，可在遺跡按 B 花 1 點打開通路。螢火燈送達出口後會保留，結算後能在寵物窩展示。

孵化室一次可放一顆蛋。現行 v9 的前四顆依序是免費立即、36 金幣／2 分鐘、54 金幣／5 分鐘、72 金幣／10 分鐘，之後每顆再加 18 金幣、5 分鐘。離線也計時。既有 Sheets 欄位可保存蛋與冒險進度，更新遠端需要重新匯入產物。
